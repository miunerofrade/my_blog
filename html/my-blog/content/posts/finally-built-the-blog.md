从学期初就想搞个博客了。事情的起因是我在网上闲逛的时候，偶然看见一个同一级的同学的博客。他居然在25年9月就搭好了，真不是一般人。搭博客的过程也挺离谱的，我以为大家都是从0手搓的，没有想到居然可以套模板的。等我知道这个的时候已经快做完了。中间也停滞了好久，好在总算是在假期搭出来了。也简单从[spaceship](https://spaceship.com)买了个域名。倒是不贵。

期间也借助了很多agent的帮助。总之，折腾了许久，这个博客终于不再只是运行在 `localhost:3000` 的本地项目了。

## 部署

还是简单介绍一下吧。本博客使用 Next.js 构建，文章直接保存在[仓库](https://github.com/miunerofrade/my_blog)的 Markdown 文件中。每次把代码推送到 GitHub 的 `main` 分支，[Vercel](https://vercel.com) 都会自动安装依赖、构建并发布新版本。

## 现在有什么

有了一个自己搓的md解析器。准确的说是借助agent的帮助搓出来的。

## 仍然会继续

上线不是结束，只是终于有了一个可以持续维护的起点。

接下来会慢慢补充真正想写的内容，之前的测试文章全都删了，现在应该让位给正式内容了。

> 先让它稳定地存在，再让内容一点一点长出来。

总之，博客终于搭好了。欢迎来到这里。
