界面变得简洁，并不意味着设计工作也随之减少。恰恰相反，当颜色、装饰和组件数量都被压缩以后，每一个间距、字号与对齐偏差都会变得更加明显。

这也是个人博客最容易遇到的问题：内容不多，却希望页面既有辨识度，又不会抢走文章本身的注意力。

## 简洁不等于空

留白首先是一种组织信息的方式，而不是为了让页面显得“高级”而留下的空地。两个元素之间的距离越大，读者越倾向于把它们理解为不同的内容组；距离越小，它们之间的关系就越紧密。

例如，一段正文与下一段正文只需要自然的呼吸感，而正文与新章节标题之间则应该有更明确的停顿。两者若使用同一套间距，页面会失去节奏。

> 留白的价值不在于它有多大，而在于它是否准确表达了内容之间的关系。

### 一个简单的判断方法

调整间距时，可以暂时忽略具体数值，只问三个问题：

1. 这两个元素属于同一个信息组吗？
2. 读者是否需要在这里停顿？
3. 这个距离在整页中是否保持一致？

如果答案不清楚，继续增加 `margin` 往往不会解决问题，只会把内容推得更远。

## 字体是一种界面结构

衬线字体适合承担标题和叙事性文本，因为它能带来更强的编辑感。无衬线字体则更适合按钮、元数据和操作提示，因为字符轮廓更直接，在小字号下也更清楚。

这两类字体可以共存，但需要明确分工：

| 内容 | 建议字体 | 主要目标 |
| --- | --- | --- |
| 页面标题 | 衬线字体 | 建立性格与视觉锚点 |
| 长篇正文 | 中文衬线或易读无衬线 | 保证连续阅读 |
| 日期、标签 | 无衬线字体 | 快速扫描 |
| 按钮文字 | 无衬线字体 | 清晰表达操作 |

## 动效应该等待用户

首屏动画可以帮助建立第一印象，但第二屏及后续内容不应该在用户尚未看到时就播放完毕。更自然的做法是让内容进入视口后再开始，并使用很短的错峰时间建立顺序。

```tsx
<motion.div
  initial="hidden"
  whileInView="visible"
  viewport={{ once: true, amount: 0.2 }}
  variants={{
    visible: { transition: { staggerChildren: 0.12 } },
  }}
>
  {items.map((item) => (
    <Card key={item.id} item={item} />
  ))}
</motion.div>
```

这里最重要的不是位移距离，而是触发时机。动效应该回应阅读行为，而不是独自表演。

## 最后的取舍

一个安静的页面依然可以有性格。性格可能来自标题字体、一个稳定的强调色，或者鼠标悬停时很轻的反馈。它不需要同时来自所有地方。

当每个组件都试图成为焦点时，页面反而没有焦点。对博客而言，最值得被看见的始终是作者的名字、文章的标题，以及真正写下来的内容。
