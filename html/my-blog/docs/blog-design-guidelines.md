# 博客设计规范

本文档是博客界面实现与验收的基线。新增页面和组件必须优先复用这里定义的字体角色、颜色、字号、间距、圆角和交互状态，不在业务组件中引入新的视觉常量。

## 1. 字体

字体数量按角色管理，而不是按字体文件总数限制：

- 无衬线界面字体：`Geist`、`SF Pro Text`、`Segoe UI`、`Microsoft YaHei`、`Arial`，按平台依次回退。
- 西文展示衬线字体：`Playfair Display`。
- 中文内容衬线字体：自托管的 `Noto Serif SC Variable`，避免构建依赖 Google Fonts 网络请求。
- 等宽字体：`Geist Mono`，仅用于代码。

同一文本块只能使用一个字体角色。中文和西文因字形覆盖发生的字体回退不算新增角色。

### 字号与行高

| 角色 | 字号 / 行高 |
| --- | --- |
| 辅助文字 | 12 / 18px |
| 小正文 | 14 / 22px |
| 正文 | 16 / 24px |
| 大正文 | 18 / 28px |
| 导语 | 20 / 30px |
| 小标题 | 24 / 30px |
| 区块标题 | 32 / 40px |
| 页面标题 | 48 / 60px |
| 大展示标题 | 80 / 96px |
| 超大展示标题 | 120 / 144px |

字号使用固定令牌和响应式断点切换，不随视口宽度连续缩放。正文行高保持 1.5 至约 1.6 倍，标题行高保持 1.2 至 1.3 倍。

## 2. 颜色

颜色必须通过语义令牌使用。禁止在组件中用透明度降低正文颜色来生成次要文字。

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| `background` | `#f8f8f7` | `#282c34` |
| `surface` | `#ffffff` | `#21252b` |
| `surface-hover` | `#fafaf8` | `#2c313a` |
| `foreground` | `#1d1d1f` | `#c7cbd3` |
| `muted` | `#707071` | `#9da5b0` |
| `accent` | `#d97959` | `#d97959` |
| `accent-foreground` | `#ffffff` | `#ffffff` |
| `success` | `#237a3b` | `#75c58b` |
| `warning` | `#8a5700` | `#f0c36a` |
| `error` | `#b42318` | `#ff8a80` |

普通文字与背景对比度必须达到 WCAG 2.1 AA 的 4.5:1；大号粗体文字至少 3:1。边框、焦点环和交互图形至少达到 3:1。

## 3. 间距与网格

- 间距令牌：8、16、24、32、40、48、64、80、96px。
- 移动端页面左右边距统一为 16px；桌面端为 24px。
- 桌面页面使用 12 列网格和 24px 槽宽；移动端退化为单列。
- 按钮、图标按钮和主导航使用 44px 最小点击热区；文章 tag 作为紧凑元数据链接使用 32px 高度、12px 左右内边距。1px、2px 边框属于绘制例外，不受 8px 间距规则限制。
- 动画位移、图像固有尺寸和按比例计算的媒体尺寸不属于布局间距。

## 4. 圆角与组件

| 场景 | 圆角 |
| --- | --- |
| 小模块、输入框 | 8px |
| 按钮 | 12px |
| 卡片、弹层 | 16px |
| 圆形图标按钮、头像、标签 | `50%` 或 `9999px` |

首页首屏三个按钮与其他命令按钮统一使用 12px 圆角，同时保留原悬停、按压动效。

所有交互控件必须具备默认、悬停、按下、键盘聚焦和禁用状态。图标按钮必须有可访问名称；移动端和桌面端点击热区均不得小于 44×44px。

## 5. 图标

- 通用界面图标优先使用 `lucide-react`，统一为 24×24px、2px 描边。
- Lucide 缺少的品牌图标使用可信公开图标库的官方 SVG，并在代码中注明来源和许可。
- QQ 品牌图标采用 Simple Icons 16.27.0 的 `icons/qq.svg`，许可为 CC0-1.0。
- 禁止为已有标准图标手绘 SVG。站点 Logo、文章图片、图表和 Mermaid 输出不属于界面图标。

## 6. 搜索与导航

- 默认只显示 44×44px 搜索图标按钮。
- 导航栏搜索按钮复用全局命令面板，在页面上方居中显示并使用背景遮罩，不挤压或移动页面内容。
- 桌面搜索面板宽度为 `min(视口宽度 - 64px, 1152px)`，输入区高度 112px，结果项高度 64px，列表四周内边距 32px。
- 移动端面板宽度为 `视口宽度 - 32px`，输入区高度 80px，结果项高度 52px，列表四周内边距 16px。
- 候选项统一用 8px 间隔区分，不使用分隔线。
- `Ctrl/Cmd+K` 或导航栏搜索按钮打开同一搜索面板；`Escape` 或点击外部关闭，关闭后焦点返回触发按钮。
- 搜索、移动导航抽屉和文章 Mega Menu 不得同时打开。

文章详情页的桌面目录条目使用 16px 字号、24px 行高、36px 最小高度和 4px 条目间隔。

## 7. 交付与验收

- 组件必须复用语义令牌，不能新增孤立颜色、字号、间距或圆角。
- SVG 保持矢量格式；位图按实际显示尺寸提供足够像素密度。
- 交付前运行测试、ESLint、TypeScript 和生产构建。
- 设计工具中的图层采用“模块-元素-状态”命名，并为复杂交互附带状态说明。
